# Project context — Míre

> Project-owned file (loaded by CLAUDE.md). Keep it short and current; details live in specs.

## Product
**Míre** — personal (and later family) finance management app. Tagline: *"Wisdom for your personal wealth."* / *"La sabiduría de cuidar lo tuyo."*
- Name: Quenya for "jewel, treasure, precious value". Spelling: **Míre** in text, **MĪRE** in the logo, `mire` in code. Formerly NÖM (renamed 2026-10-24: name already taken).
- Repository: `mire-app/start` (public; formerly `nom-finance/app`). Web: `https://mire-app.github.io/start/`.
- Brand identity and tone of voice: `docs/brand.md`. Visual tokens (palette, Sora, logo, motion): SPEC-0003.
- Palette "Noche y esmeralda": Deep Night `#0B132B` dominant, emerald `#10B981` for growth, matte gold `#E5C158` for value, off-white `#F8FAFC` background.

## Constraints
- Built with Claude Code on the web (cloud Linux sessions) under a **Claude Pro** plan: usage limits → focused sessions, a new session for each `/actuar`.
- Models: Sonnet (main session, andreth) and Haiku (balan). Priority: balanced.
- Data: personal and family financial data under **GDPR**. Data entry is **import only** (CSV, .xlsx and MyInvestor PDF); no manual entry. **No bank connections** (no PSD2).
- Cost of a production error: medium. One person (the owner) develops and decides.
