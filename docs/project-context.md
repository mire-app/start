## Product
**NÖM — Next Optimal Money.** Personal and family finance management app: *"Sabiduría financiera personal para proveer a tu futuro."*
- Name: *Nóm* ("Wisdom"), the name the House of Bëor gave Finrod Felagund. Brand spelling: NÖM; identifiers: `nom`.
- Branding: emerald/mint green = primary (*Wisdom & Growth*); graphite/slate grey = structure (*Structure & Security*); matte gold = accents (*Value*: goals reached, savings margins). Exact hex values: to be defined in the design-system spec.

## Constraints
- Built with Claude Code on the web (cloud Linux sessions) under a **Claude Pro** plan: usage limits → focused sessions, a new session for each `/actuar`.
- Models: Sonnet (main session, andreth) and Haiku (balan). Priority: balanced.
- Data: personal and family financial data under **GDPR**. Data entry is manual plus CSV/Excel import. **No bank connections** (no PSD2).
- Cost of a production error: medium. One person (the owner) develops and decides.
